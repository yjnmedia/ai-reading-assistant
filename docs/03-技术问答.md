# 技术问答

## 关于对接

**1. 这和我们（起点 / QQ阅读）已有的 AI 功能是什么关系？**

不是替代，是补两块你们现在没有的：

- **读者自己的疑问没人答**：段评/本章说解决「一起吐槽」，解决不了「这句话什么意思」「这人是谁」；
- **读者想看见那一场却没有图**：角色卡是作者/官方维护的，段评里没有图。

这两块都是「读者在自己读到的那一句上提问/提需求」，所以入口只能做在阅读器里，做在外部的对话框里没人用。

**2. 接入要改客户端吗？**

要，但只有三个很薄的点：选中文字时发「当前位置前 200 字 + 问题」、段末发原文要一张图、进书时报书名作者加一个文件头。

**唯一必须改动阅读内核的地方**是：把你的「当前位置」在发送时换算成**前 200 字原文**。这个锚点不依赖章号，这是整套方案能不能跨版本复用的前提。

**3. 要不要把书交给你们？**

不用。索引建在你自己的机器上（或者我们部署到你机房），每次问答只上传「前 200 字 + 问题」这一小段。

**4. 能不能只买提示词和索引管线？**

能。这是第三种接法：给方法不给服务——三档解释的提示词与参数、四条设计原则、五段式生图规则、MinHash 认书算法，接你们自己的模型与中台。

**5. 我们已经有自己的角色卡，怎么和你们的对上？**

按**角色名 + 外观描述**对接，不改你们的角色数据结构：你们的角色卡提供名字与一段外观描述，我们这侧生成定妆图（可多版），出场画面按「章节 + 段号 + 角色名」回挂。你们只需要多存一个「图 → 角色」的映射。

**6. 一张图反推提示词，是不是等于复刻别人的画？**

不是。它输出的是**一段可编辑的中文描述**（服饰、姿态、环境、光线、色调），不是把原图放大或重绘。用途是「我有一张喜欢的构图，想照着这个感觉画我自己的角色」。做不到像素级一致，也做不到还原原作者风格——这是技术边界，也是版权边界。

## 关于检索

**7. 为什么不用向量数据库？**

向量库解决「语义相似」，我们要解决「绝对不越界」。剧透是零容忍的，检索条件必须是 `ch_global < 当前章` 这种硬约束，向量召回给不了这个保证。

**8. 怎么保证不剧透？**

三道，最里面那道是物理的：

1. 客户端只报位置，不报章号；
2. 服务端用前 200 字唯一定位后，SQL 硬条件只取当前章之前的材料；
3. 提示词里再写一遍「不要剧透」。

模型拿到的材料里根本不含后文，所以问后文才有的名字，它只能答「前文没有提到」。

**9. 同一本书的不同版本怎么认？**

书名 + 作者先建候选桶，桶内用 MinHash/KMV（4096 个最小 9-gram）比对：≥0.90 同书、0.60~0.90 待确认、<0.60 不同书。实测同书不同版本 **0.9956**、两本无关的书 **0.0000**。

**10. 为什么「为什么」这一档必须给整章？**

实测：只给上一章末尾 1000 字，答案材料不足率 **5→5（完全没降）**；给整章才降到 0。因为「为什么」问的是因果，因果链往往在本章前半段就铺完了。

**11. 为什么两家模型要共用一份提示词？**

同一段写官场灰色操作的情节，豆包会往概念解释靠（把受贿说成「商业贿赂」），DeepSeek 直说罪名与当年普遍程度。词一样，差异才是模型倾向；词不一样，就分不清是模型问题还是提示词问题。**改一边必须同时改另一边。**

**12. 为什么提示词里要写「不替任何一方辩护」？**

早期版本要求每条都写「小说里…现实里…」，结果被读成给体制洗白：写公车私用只谈「制度进步」。正确做法是客观陈述——是违规就说违规、是普遍现象就说普遍，不加「个别现象」这类平衡话，也不反向嘲讽。

## 关于生图

**13. 为什么不走云服务？**

四条：显卡与权重不出门、成品图不回传第三方；不用养常驻 GPU（一张张排队，闲置零成本）；与检索共用同一条 mTLS 通道，客户端只多一个「提交任务」；画质档、尺寸上限、内容策略都能自己定。

**14. 为什么是「提交即返回」而不是「点了就出图」？**

一张图 40 秒到几分钟，任何同步等待都会让用户以为卡死。所以提交立刻拿任务号，界面显示「已提交，正在画…·已等 N 秒」，画好再回填。连提多张时底部显示「正在生成（k/n）」。

**15. 内容策略谁定？**

服务端。客户端只透传一句「修改意见」，不做过滤；关键字（如 `nsfw`）由服务端解析，涉未成年人一律拦截。

## 关于范围

**16. 能直接给我装一个吗？**

仓库里只有方案与实测数据，没有客户端程序——演示壳基于开源阅读器改造，仅用于验证，不对外分发。

**17. 许可与商用？**

文档与图为本项目原创，引用请注明出处。方案与实测数据可自由引用；如需商用部署（私有化、代理接入），另行沟通。

**18. 做不到的部分也说清楚。**

- 需要一台长期开机的机器放索引与画图，不是纯云服务；
- 索引是一次性成本，约 5.4 元/本、25~30 分钟；
- 生图一张 40 秒起，4K 分钟级；
- 解释的质量取决于索引摘要质量，粗粒度合并（5 章合一）能省钱但正确率从 8/8 掉到 3/8，所以不做。
